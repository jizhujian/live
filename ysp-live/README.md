# 央视频全频道 IPTV 直播网关 (ysp-live v9.0 旗舰四层兜底版)

> **极简·纯粹·单端口**：原生集成了真 4K/8K 超高清、全频道高码流、双设备热备池（Hot-Standby）、7 天时移回看、切台毫秒秒开、以及工业级四层故障平滑兜底机制的旗舰 IPTV 代理服务。

---

## 🌟 特性亮点

* **📺 真 4K / 8K / 全量 26 路高码率超高清**：默认全部 26 个核心央视频道（CCTV-1~17、4K、8K、16 4K、CGTN系列）走设备协议原生高码流（50fps、8~12 Mbps），色彩细腻无拖影。
* **⚡ 双设备热备池 (Hot-Standby Pool)**：内存常驻主备双设备会话，当主设备达到安全配额或遭遇风控时瞬间 0ms 无缝切轨，彻底消除切台卡顿 15 秒的痛点。
* **🛡️ 400 智能自愈与免降级重试**：遇到服务端风控限制时，现场毫秒级启用热备设备自动重试，确保当前频道不被无辜降级到 1080p。
* **🚀 极速快路径注册 (Fast-Path)**：精简握手流程，异步化非核心埋点，新设备注册耗时从 15 秒压缩至 1 秒以内。
* **🔒 单设备安全配额与智能流控**：默认全部 26 个高码率频道走设备协议，单设备 6 路安全配额，达到配额自动 0ms 平滑轮换热备设备，兼顾画质与安全。
* **🛡️ 独家四层全自动兜底体系**：
  * **第一防线（设备投屏原生高码流）**：直连官方硬件投屏接口，原生 12Mbps 明文高速流，免解密，画质天花板。
  * **第二防线（JCE 1080p 动态解析）**：前代经典高可用链路，保障央视核心频道不断流。
  * **第三防线（bkliveinfo 备用通道）**：官方备用协议，自动填补特殊时段空缺。
  * **第四防线（Node.js Web WASM 引擎兜底）**：内置双 WebAssembly 官方签名与 Web 流媒体解析，当 App 协议遭遇大范围风控时秒级无缝接管，电视端不黑屏、不报错。
* **⏪ 7 天时移回看 (Catchup)**：完整集成标准时移协议，完美兼容 TiviMate、Apple TV (APTV)、PotPlayer、Kodi 等主流播放器随意拖动进度条倒回播放。
* **⚡ SWR 毫秒秒开微缓存**：引入工业级 Stale-While-Revalidate 机制，切台瞬间出画面，彻底消除黑屏转圈。
* **🚀 单端口架构，对外仅开放 8767**：客户端永远只需连接 `:8767` 单端口。第四层 Web 引擎通过内部代理无缝桥接，播放器无需配置多个端口。
* **📦 纯单文件、两大纯净分类**：默认内置全部 64 路高清频道，严格划分为两大清晰分类：**央视（30路）** 与 **卫视（34路）**，无需任何外部 yaml 文件。
