## 🛠 Python 9.8 更新说明

下载文件名与运行版本统一为 9.8。本次为版本与说明更新，沿用上一补丁的功能修复，不新增“全部频道恢复”的保证。

本次针对 JCE 播放列表中很小的 PDT（节目日期时间）交叠调整判定。用户运行 9.7 时，北京卫视（bjws）重复出现 0.120 秒交叠错误；这不是所有失败频道的共同原因。

- **有界容差**：仅接受时间仍单调向前、且交叠同时不超过 0.15 秒和相邻分片时长 5% 的情况。内部保留真实时间戳；输出时可省略含歧义的可选 PDT 标签，不编造或任意移动时间戳。真正的时间倒退或较大交叠仍阻止。
- **故障区分**：江苏卫视（jsws）出现上游实际限流后，东方卫视（dfws）与浙江卫视（zjws）进入共享冷却。补丁不更改限流规则，也不宣称这些频道已恢复播放。
- **限流退避**：JCE 请求全局串行，间隔至少 2 秒；业务限流或 HTTP 429 触发共享冷却，首次 60 秒，连续限流递增至 900 秒，并遵守更长的 Retry-After。冷却期间不额外请求 JCE，也不切换提供方绕过限流。
- **减少无效刷新**：低码率频道无新播放请求超过 20 秒后停止后台轮询，各频道独立判断；成功拉取的缓存仅在 30 秒新鲜期内复用。
- **调整冷启动顺序**：仅对符合设备接口条件的频道生效；已有有效低码率缓存时仍可先复用缓存。仅支持低码率的频道继续使用低码率路径，不强行切换设备接口。
- **保持接口边界**：不修改高码率与 4K 设备协议；独立 JS 脚本本身保持不变。启播顺序调整不用于绕过上游限流，原有限流退避仍然生效。
- **低码率滚动窗口**：复用有效的 JCE 低码率滚动播放列表，只输出已完成的分片，并保留一个分片的安全余量；不支持或已冻结的数据不会被重新标记为直播，限流冷却仍然生效。
- **验证范围**：本补丁的真实播放效果尚未确认，未完成 iOS 端到端实机验证。

> 退避是尊重上游限流，不是绕过限制。上游仍在限制时可能暂时无法启播；反复重启、刷新或切台不会保证恢复。不承诺所有频道或所有网络下始终可用。

## 💻 电脑版使用方法（PC / Mac / Linux）

1. 下载地址：<https://garysclub.sharewithyou.dpdns.org/ysp-live/ysp-live-v9.8.zip>
2. 安装 Python 3 后运行。Node.js 为可选依赖，仅在下载包包含伴生引擎且运行环境支持时使用；没有 Node.js 不影响 Python 本身启动。
3. 解压进入目录直接运行：
   ```bash
   python3 ysp-live-v9.8.py
   ```
   （可选）后台常驻运行：
   ```bash
   nohup python3 ysp-live-v9.8.py > ysp.log 2>&1 &
   ```
4. 播放器添加订阅地址：`http://localhost:8767/all.m3u`

## 🐳 Docker 版使用与升级方法

1. 下载地址：<https://garysclub.sharewithyou.dpdns.org/ysp-live/ysp-live-docker-v9.8.zip>
2. 升级前停用旧容器并保留原有持久化数据，解压进入 9.8 目录。核对 compose 中的数据挂载仍指向原目录后构建启动：
   ```bash
   docker compose up -d --build
   ```
3. 播放器添加订阅地址：
   - 电脑本机播放：`http://localhost:8767/all.m3u`
   - 局域网播放：`http://你的局域网IP:8767/all.m3u`

## 📱 APTV / iOS 使用方法

1. 升级时先停用旧服务，避免两份服务争用 8767 端口。点击 “配置” ➔ “服务” ➔ “添加服务”
2. 服务名称：`央视频直播`
3. 服务类型：`Python`
4. 代码来源选择 “远程链接”，地址填写：`https://garysclub.sharewithyou.dpdns.org/ysp-live/ysp-live-v9.8.py`
5. 点击 “加载代码” ➔ 划到底部点击 “添加服务” ➔ 打开服务开关
6. 前往 APTV “添加订阅”，地址填写：`http://127.0.0.1:8767/all.m3u`

若原服务支持更换代码链接，可将地址改为 9.8 后重新加载。iOS 环境不支持伴生引擎时，不要把“未找到 ysp-engine.js”单独视为 Python 启动失败。

## 排障与使用边界

- 原有运行数据不要清空。遇到问题先保存频道名、时间和错误类型；分享日志前删除设备标识、签名、令牌和完整播放地址。
- 健康检查：`http://localhost:8767/health`；诊断：`http://localhost:8767/diag`。其他设备访问时，将 localhost 换成服务所在设备的局域网 IP。
- 观看流量随实际码率变化，4K 通常显著高于普通清晰度。请确认网络与数据套餐。
- 本地服务请仅在可信网络使用。是否能播放仍受上游授权、网络、频道状态及运行环境影响。
